# Brand Guidelines

## Sri Sastha Textile Engineering

### Color Scheme

#### Primary Colors
- **Purple**: #7c5cdb (RGB: 124, 92, 219)
- **Light Purple**: #9b7ed9 (RGB: 155, 126, 217)
- **Lighter Purple**: #c4a8f0 (RGB: 196, 168, 240)

#### Supporting Colors
- **Accent Purple**: #a78bfa (RGB: 167, 139, 250)
- **Dark Background**: #1f1f2e (RGB: 31, 31, 46)
- **Light Background**: #f5f3ff (RGB: 245, 243, 255)
- **White**: #ffffff

#### Neutral Colors
- **Muted Gray**: #6b7280 (RGB: 107, 114, 128)
- **Light Gray**: #e0d4f7 (RGB: 224, 212, 247)

### Typography

- **Font Family**: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif
- **Headings**: Bold weight (700)
- **Body**: Regular weight (500)
- **Small Text**: Regular weight (400)

### Logo & Branding

- **Company Name**: Sri Sastha Textile Engineering
- **Short Name**: Sastha (used in navigation)
- **Tagline**: "Engineering Excellence for the Modern Textile Industry"

### Design Principles

1. **Professional**: Corporate and trustworthy
2. **Modern**: Clean, contemporary design
3. **Accessible**: Clear hierarchy and readable text
4. **Interactive**: Smooth transitions and hover effects
5. **Responsive**: Works seamlessly across all devices

### Key Design Elements

- **Cards**: Subtle borders with hover lift effect
- **Gradients**: Purple gradients for primary sections
- **Icons**: Emoji icons for quick visual recognition
- **Spacing**: Consistent 24px base unit for padding/margins
- **Shadows**: Subtle box-shadows for depth

### Hover States

- **Buttons**: Slight upward movement with shadow
- **Cards**: Border color change to primary, shadow enhancement
- **Links**: Color change to primary purple

### Visual Hierarchy

1. **Hero Section**: Large, bold headline (2.8rem) with CTA
2. **Section Titles**: 2.2rem in primary purple
3. **Card Titles**: 1.2rem in primary purple
4. **Body Text**: 0.95rem in dark color
5. **Muted Text**: 0.9rem in gray
